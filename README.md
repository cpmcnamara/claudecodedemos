# Claude Code Demos

A collection of demonstration projects and examples created with Claude Code.

## Overview

This repository contains various code examples and demonstrations showcasing different programming languages, frameworks, and common development tasks.

## Contents

- **Python Examples** - Python scripts demonstrating API clients, data processing, and more
- **JavaScript Examples** - Node.js applications and browser-based demos
- **Documentation** - Guides and tutorials for common development tasks

## Getting Started

### Prerequisites

- Python 3.7+
- Node.js 14+
- Git

### Installation

Clone this repository:

```bash
git clone https://github.com/cpmcnamara/claudecodedemos.git
cd claudecodedemos
```

### Python Examples

```bash
cd python-examples
pip install -r requirements.txt
python weather_api.py
```

### JavaScript Examples

```bash
cd javascript-examples
npm install
node todo-cli.js
```

## Examples Included

### 1. Weather API Client (Python)
A simple command-line tool that fetches weather data from a public API.

### 2. Todo CLI App (JavaScript)
A command-line todo list application with persistent storage.

### 3. File Organizer (Python)
A utility script to organize files by type and date.
