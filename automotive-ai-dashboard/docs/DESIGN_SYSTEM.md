# Design System - AI Operations Dashboard

**Built on IBM Carbon Design System**

---

## 🎨 Overview

The AI Operations Dashboard leverages **IBM Carbon Design System** - the world-class open-source design system used by IBM Cloud, Watson, and enterprise products globally.

**Why Carbon?**
- ✅ Built for enterprise and data-heavy applications
- ✅ WCAG AAA accessibility compliance
- ✅ 2px mathematical spacing system
- ✅ Gray 100 dark theme optimized for manufacturing
- ✅ 12-color data visualization palette
- ✅ Production-tested by IBM's products

**Official Resources:**
- https://carbondesignsystem.com
- https://github.com/carbon-design-system/carbon

See `/docs/CARBON_INTEGRATION.md` for complete implementation details.

## Quick Reference

### Colors
- Background: `#161616` (Gray 100)
- Cards/Tiles: `#262626` (Layer-01)
- Primary Blue: `#0f62fe` (Blue 60)
- Text: `#f4f4f4` (Gray 10)
- Border: `#393939` (Gray 80)

### Typography
- Font: IBM Plex Sans / IBM Plex Mono
- H1: 42px, H2: 32px, H3: 28px
- Body: 16px
- Weight: 300/400/600

### Spacing (2px base)
- 4px, 8px, 12px, 16px, 24px, 32px

### Data Viz Colors
Purple `#8a3ffc`, Cyan `#33b1ff`, Teal `#007d79`, Magenta `#ff7eb6`, Red `#fa4d56`, Green `#6fdc8c`
